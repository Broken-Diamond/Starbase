## Charter
Guiding principles for building and improving:

- Build systems from small, understandable components.
- Document decisions, not just procedures.
- Treat the first design as a hypothesis; implementation is the experiment.
- Prefer clarity over cleverness.
- Borrow good ideas. Credit where they came from. Improve what you can.
